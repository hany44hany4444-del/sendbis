سندبيس رايح جاي — مشروع أندرويد

مشروع أندرويد جاهز يغلّف لعبة HTML (ملف app/src/main/assets/index.html) داخل WebView.

البناء كله على GitHub Actions، فلا تحتاج Android Studio.

خطوات إنشاء ملف APK على GitHub

1. افتح github.com وأنشئ مستودعا جديدا (New repository)، مثلا باسم sendbis-game.

2. فك ضغط هذا الملف على جهازك، ثم ارفع محتويات المجلد إلى المستودع

(Add file ← Upload files)، مع التأكد من رفع مجلد .github المخفي.

• لو لم يظهر المجلد المخفي على جهازك، اضغط Add file ← Create new file واكتب المسار

.github/workflows/build-apk.yml والصق محتوى الملف الموجود في المشروع.

3. بعد الرفع (commit إلى فرع main) يبدأ البناء تلقائيا. تابعه من تبويب Actions.

ولو لم يبدأ: Actions ← Build APK ← Run workflow.

4. عند اكتمال البناء (علامة خضراء) افتح التشغيل واسحب لأسفل إلى Artifacts

وحمّل sendbis-apk (ملف مضغوط بداخله app-debug.apk).

5. انقل الـ APK إلى الموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة" إن طلب).

زر الخروج وزر الرجوع على أندرويد

• زر خروج من اللعبة (في شاشة البداية وشاشة الإيقاف وشاشتي القبض والوصول) ينادي AndroidApp.exitApp()

الموجودة في MainActivity.java فيُغلق التطبيق فعليا.

• زر الرجوع في الجهاز: أثناء اللعب يوقف اللعبة مؤقتا، وأثناء الإيقاف يستكمل، وفي القائمة يخرج.

• عند الانتقال لتطبيق آخر تتوقف اللعبة والصوت تلقائيا.

تغيير اللعبة أو الاسم أو الأيقونة

• استبدل app/src/main/assets/index.html بنسخة جديدة من اللعبة (حافظ على الاسم index.html).

• اسم التطبيق: app/src/main/res/values/strings.xml.

• الأيقونة: ملفات ic_launcher.png في مجلدات app/src/main/res/mipmap-*.

• معرّف التطبيق: applicationId في app/build.gradle (حاليا com.hany.sendbis).

ملاحظات

• النسخة الناتجة (Debug) صالحة للتثبيت المباشر. للنشر على متجر Google Play يلزم توقيع نسخة Release.

• الخط (Cairo) يُحمَّل من الإنترنت إن وُجد، وبدونه يستخدم التطبيق خطا بديلا ويعمل بشكل طبيعي.

• الاتجاه رأسي (Portrait) ومحمي من النوم أثناء اللعب.
